# 5-Star Offer Generator

In seconds a visitor decides: "can't help me" (leaves) · "might help me" (signs up, then bails) · "absolutely, and you're the best" (the target).
A weak offer is usually a weak strategy — pull advantages from the moats (`plg-bullseye-strategy`) and challenges from `plg-user-endgame` / `plg-free-model`.

Three common mistakes: **being cute** (vague, jargon: "the AI-enabled solution to your challenges") · **no enhancers** · **no structure** (a page should read like a story: meet the villain → get the power → beat the villain).

If a URL is given, fetch the homepage first and audit it against everything below; rate it 1–10.

## Phase 1 — Core offer (all three pillars, or it breaks)
- **Result** — tangible, ideally measurable outcomes tied to the user endgame. Top 3: one tangible result everyone sees, one intangible (peace of mind), one improvement. Banned: "better", "faster", "grow your business".
- **Advantage** — why 5–10x better than alternatives, not marginally. Run "why does it matter?" on each; keep what matters in this market. Should echo the moats.
- **Assurance** — top 3 objections → concrete, quantified answers (no card required; setup in X minutes; money-back guarantee; free onboarding; support response time; certifications; named customers).
Missing Result → "so what?". Missing Advantage → "why you?". Missing Assurance → "what's the risk?".

## Phase 2 — Enhancers (pick ~3; can add 5–15% signups)
- **Exclusivity** — *authentic* scarcity (real capacity limits, capped beta) and urgency (limited-time offer, cohort deadline, expiring bonus, "exploding opportunity" in the market). Never fake scarcity.
- **Bonuses** — tied to unsolved challenges, not random toasters: free course, template pack, audit, 1:1 setup. (A free automation audit + setup can lift retention, not just signups.)

## Phase 3 — Assemble the page (5 sections)
1. **Hero** — tagline = the result · sub-copy reinforcing it and prompting a start · specific CTA naming the action ("Ticket my event", not "Sign up") · optional visual · social proof.
2. **Problem** — a **spiky point of view** (mildly controversial, not universally agreed) → top challenges → land on an agreeable view. Push away non-ideal users. Test it as a LinkedIn post: no reaction = not spiky enough.
3. **Solution** — headline restating result + "how it works" in ≤5 steps · why it's the best (quantified).
4. **Risk reversal** — list every reason people didn't sign up; answer each with proof: testimonial, before/after story, guarantee, endorsements, ratings, logos, media, user counts, explorable demo, certifications. Put social proof near every section, not just one strip.
5. **CTA** — why now · what they can do right after signup · is it risk-free · the next step. No new information.

## Output
Offer canvas (results, advantages, objections→assurances, enhancers) + full page copy section by section (old vs new if auditing).
The founder/expert should own the first draft. Ship fast; A/B test against the current page when traffic allows.
