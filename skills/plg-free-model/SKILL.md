# DEEP Free Model

What goes *into* the free experience matters more than which model you pick. Successful companies exist for every model.

Three outcomes of a free experience:
1. User gains a new capability and wants more → the goal.
2. User is unchanged → they leave.
3. User gets everything → no reason to pay.
Aim: help them level up, not beat the game.

## D — Desirable: split the journey into 3 levels
From the user endgame (`plg-user-endgame`):
- **Beginner** — a problem everyone in the market has → **free**
- **Intermediate** — a problem most will eventually hit → **first paid plan**
- **Advanced** — a problem only a minority hit → **top plan**, grow with them
Write one desired outcome per level (e.g. publish an event → sell more tickets with marketing tools → save big on fees at scale).
Beginner outcome checklist: **Unique** (core value shines) · **Desirable** (ideal user truly wants it) · **Effective** (reachable in ≤7 minutes).
Avoid the **cold start problem**: free tier that requires solving an advanced problem first (e.g. analytics on videos users don't have yet).
Be generous but not overwhelming (one free course that delivers, not five that take a year).

## E — Effective: unpack challenges
List 5–10 challenges per level, typed as **product**, **knowledge** or **skill**. (AI prompt to break writer's block: "List the biggest challenges for [ideal user] to achieve [outcome].")
Rate each 1–5: 1 everyone overcomes it · 3 many mention it · 5 nobody overcomes it without help. Shortlist the top 3–5 per level.

## E — Efficient: choose solutions (PCR test)
For each top challenge, brainstorm 5–10 solutions across:
- **P**roduct (features, tools)
- **C**ontent (articles, guides, examples)
- **R**esources (interactive: templates, calculators, lists, quizzes)
Don't let product people only propose features — sometimes a blog post solves it.
Score Impact vs Cost: **Pursue** (high/low) · **White glove** (high/high — doesn't scale, but teaches you) · **Quick wins** (low/low) · **Avoid** (low/high).
Shortlist per level: top 3 challenges + 3–5 solutions. Free = everything in Beginner. For usage products, set the free units (e.g. 3 boards, 25 videos) and how long users need to see value.

## P — Polished: pick the model
| Model | What | Use when |
|---|---|---|
| Opt-in free trial | Time-limited, no card | Value reachable within 7/14/30 days |
| Opt-out free trial | Card upfront | Last resort: spam, costly setup, manual onboarding. Higher % conversion, fewer starts, usually less money overall |
| Usage-based trial | Limited *amount of all* the value | Value grows with use; no time pressure (3 boards, 50 notes) |
| Freemium | Unlimited *amount of some* value, forever | Skill progresses beginner → advanced; powerful but risky; attracts non-payers |
| New product | A separate free tool solving the blocking beginner problem | Users can't reach value because of a prerequisite |
| Sandbox | Clickable demo with sample data | Long time-to-value; last resort or complement |
First launch: pick one model; no hybrids until the basics work.
Worked signal: if value builds over time (knowledge bases, CRMs), a short time trial will underperform freemium/usage.

Services and non-software: the Beginner level can be a free audit, a genuinely useful free course, or a consultative session that delivers a real result — as long as people would pay for it.

## Output: One-Page Free Model
Desired outcome (framed as a result, not features) · model + reason · top challenges · 3–5 solutions given away · ideas parked for later. Also the 3-level table for `plg-value-ladder-pricing`.
Expect the first version to miss; launch and learn fast.
